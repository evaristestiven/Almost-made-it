# Almost Made It! — WORLD-25

Download the complete Godot/Xogot project from the **[WORLD-25 release](https://github.com/evaristestiven/Almost-made-it/releases/tag/WORLD-25)**.

Choose **Almost-Made-It-WORLD-25.zip** under Assets. The automatic GitHub “Source code” archives do not contain the game project.

## Open in Xogot

1. Download `Almost-Made-It-WORLD-25.zip` from the release Assets.
2. In the iPhone/iPad Files app, tap the ZIP to extract it.
3. Open/import the extracted `AlmostMadeIt-WORLD-25/project.godot` in Xogot.
4. Allow Godot to regenerate its import cache, then verify the project title is **Almost Made It! WORLD-25**.
5. Run and select **Level 1: First Steps**.

This build enhances the five Level 1 environment areas using existing Quaternius assets. Gameplay collision geometry, controls, camera and Levels 2–10 are preserved.

Validation: 38 source runs / 1,683 assertions; 18 packaged suites / 911 assertions; 115 script parse checks; seven gameplay-camera before/after pairs. Tested with Godot 4.6.3, Compatibility renderer. Xogot device performance is unverified. Some terrain faceting and sky banding remain.

The release includes the detailed test report and a SHA-256 checksum. The complete project, asset source files and rendered screenshots are inside the project ZIP.
